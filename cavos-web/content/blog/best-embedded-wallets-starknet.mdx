This guide lists [embedded wallet](/embedded-wallet) options for **Starknet**, based on each vendor's own documentation as of November 2026. ## The short answer (November 2026)

**What is the best wallet for Starknet?** For app developers embedding a wallet inside a product, not for a user installing an extension.

- **Cavos:** audited OpenZeppelin AccountUpgradeable v3.0.0, stark key derived on the device, paymaster sponsorship. Connect never deploys; the first execute deploys and runs atomically.
- **Cartridge Controller:** gaming session keys and policy-based approvals. Use for onchain games.
- **Chipi Pay:** passkey Starknet wallets; Chipi paymaster pays gas. Use for payments.
- **Privy:** sign-only (tier 1). You deploy the account and pay gas. Use if Privy is already the EVM signer.
- **MetaMask Embedded Wallets:** exposes a private key for starknet.js. You choose the account and gas.

Not listed: Dynamic (Starknet is not on the JS/React Tier 1 native table) and Turnkey (published curves are secp256k1, Ed25519, and P-256, not the Stark curve). Recheck those vendor pages before you promise a network.

## How we evaluated

- **Starknet depth.** Deploys an account and executes multicalls, or only produces a key.
- **Account contract.** Which implementation and whether it is audited.
- **Gas.** Paymaster sponsorship or user-funded.
- **Custody.** Who can produce a signature.
- **Fit.** General consumer apps, games, or payments.

## Account contract versus sign-only in 2026

On Starknet every wallet is an account contract. Providers that deploy and execute (Cavos, Cartridge Controller, Chipi Pay) choose that contract for you. Sign-only layers (Privy tier 1, MetaMask Embedded Wallets exposing a key for starknet.js) leave the account class and the paymaster to you.

Cavos uses an audited OpenZeppelin account contract, not a custom Cavos class. Cartridge documents a Controller account with session keys for games. Chipi documents passkey wallets plus its own paymaster. Recheck those vendor pages before you commit to an account class.

## When each one fits

- **Cavos** fits consumer Starknet apps that want an audited standard account, sponsored gas, and the same SDK on Solana and Stellar.
- **Cartridge Controller** fits onchain games that need session keys and a gaming identity layer.
- **Chipi Pay** fits payments apps, especially in Latin America, that want passkey wallets plus bill payment services.
- **Privy** and **MetaMask Embedded Wallets** fit teams already on those platforms for EVM that are willing to build the Starknet account and gas layer themselves.
