title: Recovery codes
description: Cavos wallets do not use recovery codes. Starknet, Solana, and Stellar restore the MasterDEK with an enclave sign-in or a passkey.
---

Cavos wallets on Starknet, Solana, and Stellar do not use recovery codes. Each
account has one key derived from a **MasterDEK**, and a new device restores
that MasterDEK in one of two ways:

| Way back | What the user does | Setup |
|---|---|---|
| [**Hardware-isolated recovery**](/docs/hardware-isolated-recovery) | Signs in again with Google, Apple, GitHub, or an email code | `socialRecovery: true` or `deviceApproval: "enclave"`, plus the environment toggle in the dashboard |
| [**Passkey**](/docs/passkeys) | Verifies with Face ID / Touch ID / PIN on a synced passkey | `enrollPasskeyDefault()` after sign-up |

```ts title="TypeScript"
// Enclave: signing in again on the new device unwraps the MasterDEK.
// Passkey, when the user dismissed the prompt at sign-in:
const { approveDeviceWithPasskey, walletStatus } = useCavos();
if (walletStatus.needsDeviceApproval && walletStatus.hasPasskey) {
  await approveDeviceWithPasskey();
}
```

## Product guidance

- Turn on the enclave, offer a passkey, or both, before users hold real funds.
- Verify restore on physical iOS and Android devices before a production release.
- If the user loses every device and neither the enclave nor a passkey was
  enrolled, Cavos cannot restore access. That is the cost of a non-custodial
  wallet, not a gap in it.

See [Recovery](/docs/recovery), [Multi-device](/docs/multi-device), and
[Passkeys](/docs/passkeys).
