---
title: Toll
description: Pay Solana fees in the token you already hold. An account with nothing but USDC transacts without ever holding a lamport.
---

Solana charges fees in SOL and only SOL, so somebody with lamports has to be
the fee payer. **Toll** is that somebody: it signs as fee payer, and in the same
transaction the user settles in a token they already hold.

Atomic — if anything fails, the payment reverts with it.

The Solana sibling of [Reserve](/docs/reserve), and smaller than it: because
the fee payer is never the user, nothing has to be swapped inside the
transaction.

## Use it

Point the SDK at Toll and pick the route per call.

```ts title="TypeScript"
import { Cavos } from "@cavos/kit";

const wallet = await Cavos.connect({
  chain: "solana",
  network: "testnet",
  appSalt: "my-app",
  identity: { userId: user.id },
  tollUrl: "https://toll.cavos.xyz",
});

const USDC = "4zMMC9srt5Ri5X14GAgXhaHii3GnPAEERYPJgZJDncDU"; // Circle devnet USDC

if (wallet.chain === "solana") {
  await wallet.execute(1_000_000n, recipient, { fee: { token: USDC } });
}
```

The wallet needs no SOL. It does need the token, and a token account for it.

Omit `tollUrl` and that route is simply unavailable; `'self'` and `'sponsored'`
are unaffected.

<Callout type="info">
Devnet only for now, at `https://toll.cavos.xyz`.
</Callout>

## Not custodial

Toll is a fee payer, never a spender.

- It co-signs a transaction the **user** signed, and cannot alter the
  instructions inside it.
- It never holds a user key and never becomes the source of a transfer.
- The gate is a prohibition rather than an allowlist: the fee payer may not
  appear in any instruction, and the treasury may appear exactly once, as the
  destination of a payment matching the quote. An allowlist of instructions is
  how a service ends up blocking one way to spend it and not the next.

Payment is a `TransferChecked`, never a bare `Transfer`: it names the mint and
decimals in the instruction, so a look-alike token cannot settle a quote.

## What it costs

A quote is the price and the ceiling at once — the limits it carries are what
the service enforces at submit time, so a caller cannot be quoted for a cheap
transaction and then submit an expensive one.

Pricing is a floor and a margin, whichever is larger. A percentage of a Solana
fee rounds to nothing: an ordinary transfer costs about a tenth of a cent, and
a margin on that is not a price. What is being bought is not needing SOL at
all, and that does not get cheaper when the network does. Under congestion the
margin takes over from the floor.

## Rent is never fronted

Creating a token account costs a **rent deposit** — about 150× an ordinary
transaction. That deposit lives inside the account and only its owner can
reclaim it, so paying it would hand the user money that can never come back.

Toll refuses those transactions rather than pricing them. A recipient who has
no account for the token has to open it themselves.

## Accepted tokens

An allowlist, never empty. A mint is 32 bytes anybody can create, and a token
named "USDC" is worth nothing unless it is *the* USDC — a service that accepted
whatever a caller named would accept worthless look-alikes as settlement.

`GET https://toll.cavos.xyz/v1/tokens` lists what it takes and where each one
is paid.
