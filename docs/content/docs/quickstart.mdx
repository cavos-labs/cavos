title: Quickstart
description: Install @cavos/kit, choose a chain adapter, and execute your first sponsored transaction.
---

The onboarding contract is shared across every Cavos adapter: authenticate,
connect, wait for a ready wallet, then execute using the selected chain's native
method.

## 1. Install

```bash title="Terminal"
npm install @cavos/kit
```

Create an app in the [Cavos dashboard](https://cavos.xyz/dashboard) and copy its
App ID. Starknet sponsorship also requires a paymaster API key. The current web
SDK receives that value in browser code, so it must be treated as a
**client-visible, app-scoped sponsorship credential**, never as an operator or
treasury secret. Before production, bind and limit it by app, environment,
origin, rate, and spend in the sponsorship service.

## 2. Connect

This Solana example needs only the public App ID in the browser:

```ts title="TypeScript"
import { Cavos } from "@cavos/kit";

const wallet = await Cavos.connect({
  chain: "solana",
  network: "testnet",
  appSalt: "my-app",
  identity: {
    userId: user.id, // stable, immutable identifier
    email: user.email,
  },
  appId: process.env.NEXT_PUBLIC_CAVOS_APP_ID,
});

console.log(wallet.address);
```

`Cavos.connect` authenticates or accepts your identity, resolves the
deterministic wallet, creates or loads local device authority, and provisions
the chain account when required.

## 3. Execute

The return value is a discriminated union. Narrow on `wallet.chain` so
TypeScript exposes the correct native method:

```ts title="TypeScript"
if (wallet.status !== "ready") {
  // Handle a returning wallet on a new device.
  throw new Error("Device approval required");
}

if (wallet.chain === "starknet") {
  await wallet.execute(calls);
} else if (wallet.chain === "solana") {
  await wallet.execute(1_000_000n, solanaRecipient); // lamports
} else if (wallet.chain === "stellar") {
  await wallet.execute(1_000_000n, stellarRecipient); // stroops
}
```

For arbitrary execution, Starknet accepts multicalls, Solana exposes
`executeInstructions`, and Stellar exposes `invokeContract`. Each path has
adapter-specific validation and sponsorship rules.

## 4. Configure the selected adapter

| Adapter | Required configuration | Sponsored execution |
|---|---|---|
| **Starknet** | App ID, network, app salt, identity, trusted paymaster integration | Paymaster sponsors deploy and execute. |
| **Solana** | App ID, network, app salt, identity | Hosted relayer becomes fee payer; arbitrary programs are allowlisted per app. |
| **Stellar** | App ID, network, app salt, identity | Hosted relayer can sponsor reserves and fee-bump submission. |

Use the dedicated [Starknet](/docs/starknet), [Solana](/docs/solana), or
[Stellar](/docs/stellar) guide for production configuration.

## 5. Handle device approval and recovery

`status === "needs-device-approval"` means the identity already owns a wallet
but this device is not enrolled. Do not create a second wallet. Route the user
through [Multi-device](/docs/multi-device), a synced [Passkey](/docs/passkeys),
or the adapter's [Recovery](/docs/recovery) path.

<Callout type="info">
Passkeys and recovery share a product goal across chains, but their cryptographic
implementation differs. Use the high-level wallet methods and follow the
selected adapter's capability notes.
</Callout>

## React

For UI applications, use the bindings from `@cavos/kit/react`:

```tsx title="app/providers.tsx"
import { CavosProvider } from "@cavos/kit/react";

export function Providers({ children }) {
  return (
    <CavosProvider
      config={{
        chain: "solana",
        network: "testnet",
        appSalt: "my-app",
        appId: process.env.NEXT_PUBLIC_CAVOS_APP_ID,
      }}
      modal={{ appName: "My App" }}
    >
      {children}
    </CavosProvider>
  );
}
```

Continue with [React](/docs/react), [React Native](/docs/react-native), or the
full [API reference](/docs/api-reference).

If something does not behave as described here, [Troubleshooting](/docs/troubleshooting) lists the symptoms integrators hit most and what actually causes them.
