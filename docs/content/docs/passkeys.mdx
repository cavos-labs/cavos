---
title: Passkeys
description: Add a passkey after login. On Solana and Stellar it is a KDF of the MasterDEK. On Starknet it is an on-chain approver. Login never prompts for it.
---

Login with Google / Apple / email **does not** ask for a passkey. The app
decides when to enroll (`enrollPasskeyDefault`) and when a new device restores
with it (`approveDeviceWithPasskey`).

The passkey's role depends on the chain:

| Chain | How the passkey works | Can it spend? |
|-------|----------------------|----------------|
| **Solana / Stellar (native)** | WebAuthn **PRF** is HKDF of the MasterDEK (`cavos-master-dek-passkey-v1`). `connect({ passkey: true })` remints the same spend key. | **Yes.** Anyone with the synced credential can spend. Not 2FA. |
| **Starknet** | Synced WebAuthn credential registered **on-chain as an approver**. It authorizes adding a new device's P-256 key. It never signs transactions. | No. Device-approval step-up. |

`deviceApproval: "passkey"` is **one chain**. A passkey is not a multi-chain
session: use `deviceApproval: "enclave"` when Solana, Stellar, and Starknet
share a login.

<Callout type="info">
**Default:** `secureStep` is `'off'`. The built-in modal will not show "Secure
your account" after signup. Call `enrollPasskeyDefault()` from your own UI
(settings, first transaction, a banner). Set `secureStep: 'optional'` or
`'required'` only if you want that screen in the modal.
</Callout>

## Control when it's asked (React)

```tsx title="app/layout.tsx"
import { CavosProvider } from '@cavos/kit/react';

<CavosProvider
  config={{
    appId,
    chains: ["solana"],
    network: "testnet",
    appSalt: "my-app",
    deviceApproval: "passkey",   // single chain only
  }}
  modal={{
    appName: "My App",
    secureStep: "off",           // default — login never prompts
  }}
>
  {children}
</CavosProvider>
```

| `secureStep` | Behavior after a new account |
| --- | --- |
| `'off'` *(default)* | No passkey screen. Call `enrollPasskeyDefault()` yourself. |
| `'optional'` | Modal "Secure your account" with Skip. |
| `'required'` | Same screen without Skip. |

```ts title="TypeScript"
const { enrollPasskeyDefault, approveDeviceWithPasskey, walletStatus } = useCavos();

// After login, when you want the credential:
await enrollPasskeyDefault();

// On a new device that has no local wrap:
if (walletStatus.needsDeviceApproval) {
  await approveDeviceWithPasskey();
}
```

On Solana, `approveDeviceWithPasskey` reconnects with `{ passkey: true }` so the
PRF can derive the MasterDEK. Native Stellar does the same. On Starknet it still
submits `add_signer_via_passkey`.

## Starknet — on-chain approver

Once `status === "ready"`, enroll with `PasskeySigner` (or `enrollPasskeyDefault`,
which registers `addApprover` on Starknet wallets in the session):

```ts title="TypeScript"
import { PasskeySigner } from "@cavos/kit";

if (await PasskeySigner.isSupported()) {
  const passkey = new PasskeySigner();
  await cavos.enrollPasskey(passkey, {
    userId: identity.userId,
    userName: identity.email ?? identity.userId,
  });
}
```

On a new browser:

```ts title="TypeScript"
if (cavos.status === "needs-device-approval") {
  await cavos.approveThisDeviceWithPasskey({ passkey: new PasskeySigner() });
}
```

`approveDeviceEverywhere` is Starknet-only in practice (on-chain assertion).
Native Solana throws if you treat the passkey as an approver.

## Solana / Stellar — PRF is the KDF

Do not call `wallet.enrollPasskey(PasskeySigner)` on native Solana — it throws.
Use `enrollPasskeyDefault()`, which creates a `PasskeyPrf` credential.

A synced iCloud / Google passkey **is** the wallet on those chains. Frame it as
*"Add a passkey so you can open this wallet on any device"* — not as 2FA.

## Prerequisites

- **HTTPS or `http://localhost`.** A LAN IP fails WebAuthn. Use a tunnel for
  phones.
- Gate on `PasskeySigner.isSupported()` / platform authenticator.
- `rpId` defaults to `window.location.hostname`.

### React Native

```ts
import { NativePasskeySigner, NativePasskeyPrf } from "@cavos/kit/react-native";

const starknetApprover = new NativePasskeySigner({ rpId: "auth.example.com" });
const nativePrf = new NativePasskeyPrf({ rpId: "auth.example.com" });
```

If Android does not return PRF, restore with the enclave (if enabled) rather
than changing the account model.
